# Some Dumb Questions into Java when jumping from other programming language

- Class is a blueprint for an object, everything in Java is an object
- main() method is not necessary in every class, only required in the one that starts the program
- In Java, bool and int aren't interchangeable, you can't do while(1){}

## Some basic things
- Statements end in semicolon;
- Code blocks inside curly braces {}
- System.out.println inserts newline, while System.out.print keeps printing in same line
